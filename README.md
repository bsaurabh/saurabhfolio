# saurabhfolio

Saurabh Bajaj's portfolio: Market Hours. Plain static HTML/CSS/JS, no build step.

- `index.html`: homepage (scroll-drawn scenes, one trading day)
- `strategy-builder.html`, `pnl-alerts.html`: case studies
- `img/`: screens (demo or approved exports only)
- `vercel.json`: clean URLs
- `robots.txt`: blocks indexing until launch (remove at Gate 9)

Deploy: Vercel, framework preset "Other", no build command, output directory = repo root.
